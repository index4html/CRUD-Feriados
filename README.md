# Tarea Sumativa CRUD - Feriados Chile 2024 🇨🇱

Junto con saludar, adjunto los datos y el enlace correspondientes a la Tarea Sumativa CRUD en Python con MySQL.

El desarrollo cumple con todos los requerimientos solicitados en la pauta:

El script principal se denomina TareaCRUD.py.

Se incluye el archivo de datos fuente Feriados_2024.json.

Se implementaron las funciones para la carga masiva desde el JSON, la creación automática de la tabla feriados2024 y el menú interactivo con todas las consultas (todos los registros, religiosos, irrenunciables, rango de fechas del 11 de marzo al 31 de agosto, inserción y eliminación por nombre), incluyendo además el caso especial del feriado "Unión de los dos paisajes".

El código está documentado de forma simple y estructurado en su propio repositorio independiente.
